# Stream Vibe  
*Проект выполнен в рамках обучения Frontend-разработке.*

Проект стримингового сервиса, реализованный на базе **Minista**.
Сайт представляет собой многостраничное приложение с адаптивной версткой, 
сложными компонентами и интерактивными элементами.


## 🛠 Стек технологий:
- **Framework:** [Minista](https://minista.js.org/) (Static Site Generator на базе React/JSX)
- **Styling:** SCSS (препроцессор), БЭМ-методология, fluid typography (динамические размеры)
- **Language:** JavaScript (ES6+), JSX
- **Build Tools:** Vite (сборка), PostCSS (автоматизация CSS: PxToRem, PresetEnv)
- **Core Features:**
    - Динамическая адаптивность (Fluid Typography & Spacing)
    - Слайдеры на базе [Swiper.js](https://swiperjs.com/)
    - Интерактивные компоненты: табы, аккордеоны, модальные окна, видеоплеер
    - Работа с формами и масками ввода ([IMask](https://imask.js.org/))


## 🚀 Функционал:
- **Главная страница:** Hero-секция, список категорий и планов подписки.
- **Страница фильмов:** Полноценный плеер, система рейтинга, фильтрация контента.
- **Интерактивность:** Реализована через JS-модули (OverlayMenu, SliderCollection, TabsCollection).
- **SEO & Performance:** Оптимизация изображений, шрифты, использование современной методологии БЭМ.


## 📝 Changelog (История разработки)
`Здесь я фиксирую ключевые этапы проделанной работы:`

 ### 1.5 Файлы constants.scss и functions.scss — Sass-константы и функции
Реализована система плавного масштабирования контента с помощью функций **Sass** и CSS-свойства `clamp()`.
* **Функции `fluid()` и `fluid-to-laptop()`**: на основе математической модели и CSS-свойства `clamp()` автоматически вычисляют динамические размеры шрифтов и отступов.
* **Преимущества**:
    * **Плавность**: контент масштабируется непрерывно, без резких переходов при изменении размера экрана.
    * **Лаконичность**: существенное сокращение объема CSS-кода.
    * **Гибкость**: централизованное управление сеткой проекта через глобальные переменные в `constants.scss`.

### 1.6 : Файл mixins.scss — Sass-миксины 🛠 UI Toolkit (Sass Mixins)
Разработана библиотека миксинов для ускорения разработки и поддержания чистоты стилей:
* **Layout:** `flex-center`, `abs-cover`, `abs-center` и другие — упрощают позиционирование элементов.
* **Typography:** `fluid-text` — автоматизирует применение функции `fluid()` к размерам шрифтов.
* **Utilities:** `visually-hidden` (для доступности), `focus-visible` (единый стиль фокуса), `disabled` (стандартное состояние отключенных элементов).

###  1.7 [Текущий этап](https://github.com/maxolio/stream-vibe-final) : Файл media.scss — Sass-миксины для медиа-выражений
В проекте реализован набор миксинов для удобного управления медиа-запросами и состояниями элементов.

* **Адаптивные миксины:** Группа миксинов (`@include mobile`, `@include tablet` и др.) упрощает написание адаптивного кода, скрывая сложность медиа-запросов за интуитивными названиями.
* **Smart Hover:** Миксин `@include hover` корректно обрабатывает состояния наведения, учитывая особенности сенсорных устройств (отключает «залипание» hover-эффектов на мобильных).
