# Stream Vibe  
*Проект выполнен в рамках обучения Frontend-разработке.*

Проект стримингового сервиса, реализованный на базе **Minista**.
Сайт представляет собой многостраничное приложение с адаптивной версткой, 
сложными компонентами и интерактивными элементами.


## 🛠 Стек технологий:
- **Framework:** [Minista](https://minista.js.org/) (Static Site Generator на базе React/JSX)
- **Styling:** SCSS (препроцессор), БЭМ-методология, fluid typography (динамические размеры)
- **Language:** JavaScript (ES6+), JSX
- **Build Tools:** Vite (сборка), PostCSS (автоматизация CSS: PxToRem, PresetEnv)
- **Core Features:**
    - Динамическая адаптивность (Fluid Typography & Spacing)
    - Слайдеры на базе [Swiper.js](https://swiperjs.com/)
    - Интерактивные компоненты: табы, аккордеоны, модальные окна, видеоплеер
    - Работа с формами и масками ввода ([IMask](https://imask.js.org/))


## 🚀 Функционал:
- **Главная страница:** Hero-секция, список категорий и планов подписки.
- **Страница фильмов:** Полноценный плеер, система рейтинга, фильтрация контента.
- **Интерактивность:** Реализована через JS-модули (OverlayMenu, SliderCollection, TabsCollection).
- **SEO & Performance:** Оптимизация изображений, шрифты, использование современной методологии БЭМ.

### 1.5: Файлы constants.scss и functions.scss — Sass-константы и функции
</summary>

Реализована система плавного масштабирования контента с помощью функций **Sass** и CSS-свойства `clamp()`.
* **Функции `fluid()` и `fluid-to-laptop()`**: на основе математической модели и CSS-свойства `clamp()` автоматически вычисляют динамические размеры шрифтов и отступов.
* **Преимущества**:
    * **Плавность**: контент масштабируется непрерывно, без резких переходов.
    * **Лаконичность**: существенное сокращение объема CSS-кода.
    * **Гибкость**: централизованное управление через глобальные переменные в `constants.scss`.

### 2.2.1: Навигационное меню и логика активных ссылок - JSX часть
</summary>

В компонент `Header` интегрирована динамическая навигация с автоматическим определением активного состояния страниц.

* **Определение активной страницы:** С помощью деструктуризации пропса `url` в глобальном Layout и передачи его в Header реализована проверка текущего пути.
* **Условная стилизация:** Используя библиотеку `clsx`, настроено динамическое добавление класса `is-active`, который визуально выделяет текущую страницу в меню.
* **Компонентный подход:** Логотип и навигация разделены на логические блоки внутри шапки, обеспечивая чистую структуру JSX.

### 2.4.1 : Универсальный компонент Button - кнопка или ссылка с красным фоном основная 
</summary>

Разработан гибкий компонент кнопки, способный трансформироваться в ссылку и поддерживающий различные состояния отображения.
* **Полиморфная структура:** Компонент автоматически меняет HTML-тег (`a` или `button`) в зависимости от наличия пропса `href`, обеспечивая семантическую корректность кода.
* **Управление доступностью:** Реализована поддержка скрытых меток через `isLabelHidden`. В этом случае текст передается в `aria-label` и `title`, что сохраняет доступность для скринридеров при визуальном скрытии текста.
* **Контроль взаимодействия:**
    * Использование `user-select: none` предотвращает нежелательное выделение текста внутри кнопки при частых кликах.
    * Свойство `pointer-events: none` для состояния `disabled` полностью блокирует любые взаимодействия и события мыши.
* **Визуальный отклик:** Настроены стили для состояний `:active` (эффект нажатия через `scale`) и `@include hover`, а также реализована адаптивная верстка размеров через `fluid-to-laptop`.
</details>
