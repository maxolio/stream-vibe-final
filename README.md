# Stream Vibe  
*Проект выполнен в рамках обучения Frontend-разработке.*

Проект стримингового сервиса, реализованный на базе **Minista**.
Сайт представляет собой многостраничное приложение с адаптивной версткой, 
сложными компонентами и интерактивными элементами.


## 🛠 Стек технологий:
- **Framework:** [Minista](https://minista.js.org/) (Static Site Generator на базе React/JSX)
- **Styling:** SCSS (препроцессор), БЭМ-методология, fluid typography (динамические размеры)
- **Language:** JavaScript (ES6+), JSX
- **Build Tools:** Vite (сборка), PostCSS (автоматизация CSS: PxToRem, PresetEnv)
- **Core Features:**
    - Динамическая адаптивность (Fluid Typography & Spacing)
    - Слайдеры на базе [Swiper.js](https://swiperjs.com/)
    - Интерактивные компоненты: табы, аккордеоны, модальные окна, видеоплеер
    - Работа с формами и масками ввода ([IMask](https://imask.js.org/))


## 🚀 Функционал:
- **Главная страница:** Hero-секция, список категорий и планов подписки.
- **Страница фильмов:** Полноценный плеер, система рейтинга, фильтрация контента.
- **Интерактивность:** Реализована через JS-модули (OverlayMenu, SliderCollection, TabsCollection).
- **SEO & Performance:** Оптимизация изображений, шрифты, использование современной методологии БЭМ.


## 📝 Changelog (История разработки)
`Здесь я фиксирую ключевые этапы проделанной работы:`

- **[Текущий этап]**: ### 📱 1.5 Файлы constants.scss и functions.scss — Sass-константы и функции
Реализована система плавного масштабирования контента с помощью функций **Sass** и CSS-свойства `clamp()`.
Функции `fluid()` и `fluid-to-laptop()`: автоматически вычисляют динамические размеры (шрифты, отступы), исключая необходимость в множестве `@media` запросов.
Преимущества: плавный отклик интерфейса на любых экранах, сокращение объема CSS-кода и легкое управление масштабированием через глобальные переменные.
